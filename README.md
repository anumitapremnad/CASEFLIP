# CaseFlip

A minimal, offline-friendly text case converter. Paste your text, pick a mode, copy the result.

🔗 **Live demo:** _(add your GitHub Pages link here once deployed)_

## Features

- **UPPER CASE** — converts all text to uppercase
- **lower case** — converts all text to lowercase
- **Title Case** — capitalizes the first letter of each word
- **Sentence case** — capitalizes the first letter of each sentence
- **Reverse** — reverses the entire string
- **Remove Spaces** — collapses extra spaces and blank lines
- **Alternating Case** — alternates lower/upper case per character
- Live character, word, and sentence counters
- Copy result to clipboard with one click
- Works fully offline — no dependencies except Google Fonts

## Tech Stack

- HTML
- CSS
- JavaScript (vanilla, no frameworks)

## Usage

Just open `index.html` in any browser. No build step, no installation.

## Deployment

This project is deployed via **GitHub Pages**:

1. Push `index.html` to your repository
2. Go to **Settings → Pages**
3. Select your branch and root folder as the source
4. Your site will be live at `https://<username>.github.io/<repo-name>/`
